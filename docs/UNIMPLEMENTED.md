# 暂未实现功能清单

版本：v0.2.2
用途：说明哪些原 Web 版功能没有在本版本实现（或有意移除），以及原因与后续扩展方案。

---

## 一、语音练习

**状态**：仅保留功能识别与界面提示，不做录音 / ASR / OSS 上传。

**原因**：

- 原 Web 版该功能的脚本从未真正加载，功能本身不可用；
- 依赖 3 个非官方服务，稳定性与合规性都无法保证；
- 原实现存在字段级 bug（提交参数与接口期望不一致）。

**当前行为**：`app/services/homework.lua` 的 `isVoicePractice()` 识别语音练习，
`app/ui/pages/practice.lua` 的操作面板对语音练习只显示「语音练习（本版本不支持在应用内完成）」，
不提供提交入口，也不伪造记录。

**后续扩展**：需要引入录音权限、音频编码、ASR 服务与文件上传，属于独立功能模块，
超出本次重构范围。

---

## 二、摄像头扫码（Auth 迁移接收端）

**状态**：改为粘贴链接领取。

**原因**：已实测运行时不提供 `com.google.zxing.*`、`com.journeyapps.*`、MLKit、CameraX
等任何可用的二维码解码库；在纯 Lua 中实现 QR 解码（含定位、纠错、掩码还原）不现实。

**当前行为**：

- 生成端：纯 Lua QR 编码器 + 原生 Canvas 渲染（`app/utils/qrcode.lua` + `app/ui/chart.lua`）；
- 接收端：`app/ui/pages/transfer.lua` 的 `openReceiveFlow()`，用户粘贴二维码链接后领取 Token，
  支持从剪贴板一键粘贴。

**后续扩展**：若运行时后续提供可用解码库，只需在接收端增加扫码入口，
把识别出的链接交给现有 `transferService.receive()` 即可，服务层无需改动。

---

## 三、批量自动做题

**状态**：**有意移除**，不予实现。

**原因**：原 Web 版的「一键完成 / 多选批量执行」会用随机耗时伪造完成记录
（第一名耗时 +1~5 秒随机偏移、3~6 秒随机等待伪装真人），会污染他人可见的排行榜数据。

**当前行为**：`app/ui/pages/practice.lua` 的 `recordCompletion()` 要求用户输入**真实练习耗时**
并二次确认后提交，界面明确说明用途与合规边界；不做随机偏移、不批量代刷、不改准确率。

---

## 四、平板 / 横屏专属布局

**状态**：无专属布局，大屏下为单列拉伸。

**当前行为**：统计页摘要卡片在宽屏为双列、窄屏（< 360dp）退化为单列
（`kit.isCompactWidth()`）；其他页面按可用宽度自适应，不做多列重排。

**后续扩展**：可基于 `kit.windowWidthDp()` 增加 `sw600dp` 档位，把列表页改为双列网格。

---

## 五、登录态自动续期

**状态**：无 refresh token 机制。

**原因**：官方接口未提供 refresh token，登录态失效只能依赖服务端返回 `errcode: 44`。

**当前行为**：检测到 44 后统一走 `shell.handleAuthInvalid()`，只提示一次并回到登录页，
同时清除本机加密凭据。

---

## 六、不在范围内的事项

- 不恢复已弃用的 Python 服务端；
- 不引入 WebView 承载主界面；
- 不内置任何管理员密钥、AccessKey 或第三方私有接口凭据；
- 不实现任何形式的成绩伪造、批量代刷或数据篡改。
